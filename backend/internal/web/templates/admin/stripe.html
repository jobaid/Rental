How to wire this up

  1. Open your Stripe dashboard → Developers → API keys. Copy the Publishable key and Secret key into the form. Start in Test mode until you've charged a test card end-to-end.
  2. Still in the Stripe dashboard → Developers → Webhooks → Add endpoint. URL: https://my.2set.com/webhooks/stripe
    Events to send:
    • checkout.session.completed
    • checkout.session.async_payment_succeeded
    • checkout.session.async_payment_failed
    • checkout.session.expired
    • charge.refunded
    • refund.updated
    After creating the endpoint, Stripe shows a Signing secret starting with whsec_. Paste it into "Webhook signing secret" above.
  3. Click Save then Test connection. Green banner = OK.
  4. Open any invoice → click Send payment link. Stripe returns a URL you can copy or send via the invoice email.

Keys are stored encrypted-at-rest by the database and never sent to the browser after save. Environment variables STRIPE_SECRET_KEY, STRIPE_PUBLISHABLE_KEY, STRIPE_WEBHOOK_SECRET, STRIPE_MODE override the DB values if set — useful for keeping production keys out of the database entirely.
